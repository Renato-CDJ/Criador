
# Slide Training Pro

Projeto profissional base para editor de treinamentos.

Recursos planejados:
- Ctrl+V para imagens
- Drag and Drop
- Múltiplos slides
- Setas animadas
- Círculos e destaques
- Exportação PDF
- Exportação PNG
- Undo/Redo
- Layers
- Templates
- Zustand Store
- React + TypeScript + Konva
